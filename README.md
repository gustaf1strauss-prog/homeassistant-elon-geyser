\# Kwikot / PowerOptimal Elon Smart Geyser for Home Assistant



Local integration for the \*\*Elon Smart\*\* thermostat (Kwikot / PowerOptimal) using Home Assistant's `command\_line` component over local REST API (`/V1/DeviceStatus/Query`).



\## Features

\- 🌡️ Real-time Water Temperature

\- ⚡ Power Source Detection (Solar PV / Grid AC / Idle)

\- ⏱️ Reheat Timer

\- 🔌 Grid AC Availability Binary Sensor

\- ⚠️ Alarm/Fault Status Binary Sensor
